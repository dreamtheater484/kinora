# Reference photos

Put one folder per person here, for example `refs\person\*.jpg`. Same period as the videos,
sharp, varied angles and expressions; group photos are fine. The folder name is what the front
end shows in its *Person* list, and `upscale.bat --refs refs\person` uses the same folder.

Everything in this folder except this file stays on this PC: `.gitignore` keeps the photos out
of git.
